# Homebrew Tap for PromptConduit (Deprecated)

**This Homebrew tap is no longer maintained.** Install the CLI with:

```bash
curl -fsSL https://promptconduit.dev/install | bash
```

The CLI auto-updates in the background when new releases are published. See [github.com/promptconduit/cli](https://github.com/promptconduit/cli) for other install options.
