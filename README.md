# Homebrew Tap for PromptConduit

Official [Homebrew](https://brew.sh) tap for the [PromptConduit CLI](https://github.com/promptconduit/cli).

## Installation

```bash
brew tap promptconduit/tap
brew install promptconduit
```

## Updating

```bash
brew update
brew upgrade promptconduit
```

## Formulae

| Formula | Description |
|---------|-------------|
| `promptconduit` | CLI for capturing events from AI coding assistants |

## How This Tap Is Updated

The formula is auto-generated by [GoReleaser](https://goreleaser.com) when a new CLI release is tagged. **Do not edit `Formula/promptconduit.rb` manually** — it will be overwritten on the next release.
